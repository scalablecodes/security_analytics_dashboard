ARCHIVED — NOT PART OF THE STUDY RESULTS
========================================

CERT_performance.csv was produced by an early configuration run in which the
--dataset flag was set to "CERT" while the input file was still the synthetic
study dataset (data/events.csv). Its contents are therefore a duplicate of
SYNTHETIC-UBA-20_performance.csv and are NOT results from the Carnegie Mellon
CERT Insider Threat Test Dataset.

The CERT dataset was assessed for suitability (Chapter Three, Section 3.6) but
was not used for model development or evaluation in this study.

This file is retained here only for run provenance. It must not be cited,
reported, or displayed as study results.
